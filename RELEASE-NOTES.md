Windows x64 community preview, version 0.8.3-preview.

New: Wallet → My wallets → Show history opens a dedicated history window for the selected wallet. Browse pages, refresh, and select a transaction for full details including available memos. Wallet identity is checked before history is requested.

Download the Windows-x64 ZIP, extract everything, and run ZKasNodeManager.exe with wallet-runtime beside it. Existing data and services are reused. Source archives are not the runnable download.

The Go regression suite and Windows-target build/vet passed. Native Windows GUI behavior and live payments/mining remain unverified in this preparation environment. See VALIDATION.md. This is an unsigned, unaudited community preview.
